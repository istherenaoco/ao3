# v53 — Reader spacing controls

Added four live reader controls (all 1px steps): horizontal content padding (0–48px), line height (16–56px), paragraph gap (0–48px), and first-line indent (0–48px). Values apply immediately, persist in local storage, and are included in Google Drive reader preferences sync. Older settings default to 20/24/24/0px.

Assets: `public/assets/app-v53.css`, `public/assets/app-v53.js`.

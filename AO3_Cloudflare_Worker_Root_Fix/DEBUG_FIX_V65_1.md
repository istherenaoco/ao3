# v65.1 — 모바일 화면 디버깅

- `public/index.html`의 스타일시트 링크에 포함되어 있던 실제 텍스트 `\\n`을 제거했습니다. 브라우저 화면 상단에 `\\n`이 출력되던 원인입니다.
- CSS/JS/큐 위젯 참조에 `?v=65.1` 캐시 버스터를 추가하고 빌드 마커를 갱신했습니다. 배포 후에도 이전 JS/CSS가 캐시되어 이전 책장 버튼 배치가 나타날 가능성을 줄입니다.
- iOS Safari에서 설정/백업/북마크/수정/삭제 모달이 화면 높이를 넘거나 하단 내용이 가려지지 않도록 동적 뷰포트 높이, 안전 영역, 내부 스크롤을 보강했습니다.
- 기존 회귀 테스트에 HTML 에셋 참조 및 `\\n` 회귀 검사를 추가했습니다.

검증: `npm run check` 통과. 실제 배포 환경의 Cloudflare 캐시, iPhone Safari에서의 터치/시각 동작은 별도 실기기 검증이 필요합니다.

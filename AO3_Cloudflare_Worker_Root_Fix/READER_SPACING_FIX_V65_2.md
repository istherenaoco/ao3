# v65.2 — 본문 줄 간격 및 문단 간격 수정

- 줄 간격 설정값(15–25)을 글꼴 크기보다 작은 고정 line-height로 직접 적용하던 문제를 수정했습니다. 설정값을 읽기 좋은 line box 배율로 변환합니다.
- 문단과 원문 사이 여백을 일관되게 정리하고 문단 기본 margin/padding 충돌을 제거했습니다.
- 번역 문단 내부에 섞인 개행/탭/연속 공백을 한 칸으로 정규화해, 문단 하나 안에서 불필요한 강제 줄바꿈이 발생하지 않도록 했습니다. 실제 문단 경계는 기존 문단 데이터 구조를 유지합니다.
- 캐시 버전을 65.2로 올렸습니다.

검증: `npm run check` 통과. 실제 iPhone Safari에서의 최종 외관은 배포 후 확인이 필요합니다.

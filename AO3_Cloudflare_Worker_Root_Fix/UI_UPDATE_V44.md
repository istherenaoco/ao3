# v44 책장 UI 변경

- 책장 소개 문구와 중복된 새 AO3 가져오기/묶기 버튼 제거. 작업실은 기존 아이콘 내비게이션으로 접근합니다.
- 자동 저장 배지는 `저장됨`, Drive 배지는 `동기화됨`, `동기화 중`, `미연결`로 축약. 상세 상태는 `title` 툴팁에 유지합니다.
- 북마크 태그 필터는 접었다 펼 수 있으며, 사용자의 선택을 로컬 저장소에 기억합니다.
- 변경 자산: `public/index.html`, `public/assets/app-v44.js`; 스타일/대기열 보조 자산은 v44 URL로 제공됩니다.
- 검증: Worker/앱/대기열 JavaScript 구문 검사, ZIP 무결성, 주요 DOM ID 및 리소스 경로 확인. 실서비스 UI는 배포 환경에서 확인이 필요합니다.

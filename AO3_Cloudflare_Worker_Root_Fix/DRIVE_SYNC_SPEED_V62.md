# Google Drive 빠른 증분 동기화 v62

- Drive files.list 메타데이터의 modifiedTime/md5Checksum/size와 로컬 동기화 인덱스를 사용해 변경 없는 소설 JSON 다운로드를 건너뜁니다.
- 목록 페이지네이션(pageSize 1000, nextPageToken)을 처리합니다.
- 변경된 소설 다운로드는 최대 4개, 업로드/삭제는 최대 3개씩 제한 병렬 처리합니다.
- 소설 업로드 실패는 오류로 처리해 다음 동기화에서 재시도할 수 있도록 합니다.
- 사용자 설정/커스텀 책장 문서는 병렬로 동기화합니다.
- 최초 동기화 또는 캐시가 없는 경우에는 원격 소설 파일을 다운로드해 기준 인덱스를 만듭니다.

실계정 Google Drive OAuth/네트워크 테스트는 별도 수행해야 합니다.

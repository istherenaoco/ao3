# Bookmark manager and custom bookshelf tag filter (v20)

- The bookmark manager is presented as a saved-sentences view. Novel-level bookmark cards and paragraph-bookmark cards are disabled in the manager; saved sentence bookmarks remain visible with tag filtering, edit, and reader-jump actions.
- The custom bookshelf view includes a tag filter for all translated works and user-created author/topic shelves. The selected tag filters the current work list; tag assignment remains manual.
- Existing novel bookmarks and saved sentence data are not deleted by these UI changes.
- Validation performed for this package: HTML copies are byte-identical; inline JavaScript syntax and ZIP integrity checks are run during packaging.

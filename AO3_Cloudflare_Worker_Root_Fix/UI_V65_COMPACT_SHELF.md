# v65 책장 카드 컴팩트 UI

- 카드 안의 제목·작가·태그를 왼쪽 정렬하고 제목 영역이 카드 폭을 최대한 사용하도록 조정했습니다.
- 제목 글자 크기와 카드 안쪽 여백, 카드 사이 간격, 태그 간격을 줄여 모바일에서 한 작품이 차지하는 높이를 낮췄습니다.
- `이어보기` 표시와 `뷰어로 열람` 버튼을 제거했습니다. 제목을 누르면 기존처럼 뷰어가 열립니다.
- 하단에 북마크/태그, 작품 정보 수정, 삭제 아이콘을 배치했습니다.
- `+ 챕터 추가` 기능은 유지했습니다.
- Worker, 번역, API, Drive 동기화, 큐, 데이터 구조는 변경하지 않았습니다.
- 검증: `npm run check` 통과. 실제 모바일 기기에서의 시각적 확인은 수행하지 않았습니다.

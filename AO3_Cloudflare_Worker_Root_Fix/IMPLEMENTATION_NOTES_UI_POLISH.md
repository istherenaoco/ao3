# UI 가독성 및 소설 집중 디자인 개선

- 다크 모드에서 본문 글자 대비를 높이고 입력칸/선택창의 배경과 테두리를 명확히 했습니다.
- 빨강은 주요 동작 버튼 중심으로 절제하고, 장식적인 빨간 텍스트는 중립적인 밝은 회색으로 조정했습니다.
- 소설 본문 줄 간격, 글자 크기, 문단 간격과 챕터 제목 위계를 조정해 장시간 읽기 편하게 했습니다.
- 읽기 툴바의 테두리와 그림자를 정리하고 모바일 본문 여백을 조정했습니다.
- 루트 및 public 경로의 index.html/ao3.html 네 파일에 같은 CSS 개선을 반영했습니다.
- 검증 범위: 파일 동기화, 인라인 JavaScript 문법, ZIP 무결성. 실제 브라우저 시각 검증은 수행하지 않았습니다.

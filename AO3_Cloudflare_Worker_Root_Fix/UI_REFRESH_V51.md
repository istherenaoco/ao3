# UI Refresh v51

A visual-only refresh based on v50. The app JavaScript behavior is unchanged; `app-v51.js` is a version-pinned copy of v50 for matching deployment assets. `app-v51.css` adds a cohesive quiet-editorial design system for the header, navigation, shelf cards, filters, forms, modals, and reader chrome. It preserves reader theme canvases and existing IDs/event handlers.

## Design references
- Readwise Reader's long-form reading view: lets reading content take priority over action-heavy controls and provides typography/theme customization.
- Apple Human Interface Guidelines: emphasizes clear visual hierarchy, comfortable control sizes, spacing, legible typography, and accessible focus states.

## Visual direction
- Dark: ink-navy surfaces, restrained berry accent, softened borders and clear muted text.
- Light: cool-neutral canvas with crisp white surfaces and low-contrast borders.
- Shelf cards: subtle editorial edge accent, smoother hover response, clear title/meta/action hierarchy.
- Forms and modals: unified radii, focus states and surface treatments.
- Reader canvas itself keeps the existing paper/green/dark theme colors.

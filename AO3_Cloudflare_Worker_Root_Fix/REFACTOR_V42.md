# v42 코드 정리 내역

- 정적 자산 경로가 `./public`인 점을 기준으로 배포에 사용되지 않던 루트 `index.html`/`ao3.html` 복사본을 제거했습니다.
- 네 개에 중복 저장되던 동일 HTML을 단일 `public/index.html`로 정리하고, 기존 `/ao3.html` URL은 루트 앱으로 이동하는 호환 별칭으로 유지했습니다.
- 인라인 CSS, 앱 메인 JS, 대기열 부트스트랩을 버전 지정 자산 한 곳으로 이동해 중복과 업데이트 불일치 위험을 줄였습니다. 실행 순서는 기존 HTML과 동일하게 유지합니다.
- 누적된 v36/v37/v40/v41 제목·테마 CSS 덮어쓰기 중 구버전 셀렉터와 중복 선언을 정리하고, 제목/원제 스타일을 하나의 규칙 묶음으로 통합했습니다. 공급자 설정 색상은 기존 `applySettingsDarkPalette()` 한 곳을 단일 런타임 설정 원본으로 유지했습니다.
- 기본 번역 프롬프트의 반복 문자열을 `DEFAULT_TRANSLATION_PROMPT` 한 상수로 통합했습니다.
- 구버전 `IMPLEMENTATION_NOTES_*.md`를 제거하고 현재 기능/배포 구조를 `CURRENT_IMPLEMENTATION.md` 및 `README_WORKER.md`에 통합했습니다.
- Worker 엔드포인트, 저장 키, API 요청 형식, 번역/책장/Drive/대기열 기능의 로직은 리팩터링 목적 외에는 변경하지 않았습니다.

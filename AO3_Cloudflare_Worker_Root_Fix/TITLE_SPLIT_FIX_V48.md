# v48 제목/원제 표시 수정

## 원인
이전 수정은 `#readerNovelTitle` 뷰어 상단만 처리했습니다. 사용자가 첨부한 화면은 두 열로 표시된 책장 카드의 제목이었으며, `renderBookshelf()`는 `escapeHtml(novel.title)`로 저장 문자열을 그대로 출력해 분리 함수를 우회했습니다.

## 수정
- `renderNovelTitleMarkup()`를 추가해 메인 책장 카드, 사용자 정의 책장 목록/검색 결과, 저장한 문장 목록에서 공유합니다.
- 번역 제목은 기존 제목 스타일로, 원제는 괄호 없이 바로 다음 줄에 작은 회색 글씨로 표시합니다.
- 저장된 `novel.title`은 변경하지 않아 검색, 정렬, 동기화, 편집에 영향이 없습니다.
- 배포 자산명을 `app-v48.js` / `app-v48.css`로 바꿔 구버전 자산 캐시를 우회합니다.
- 책장 카드에 `data-title-split-version="48"` 진단 속성을 추가했습니다.

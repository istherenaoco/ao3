# Azure Translator 자동 사용 토글 (v101)

## 변경 사항
- API 설정창의 Azure Translator 카드에 `Azure Translator 자동 사용` 체크박스를 추가했습니다.
- 체크를 끄면 자동 번역 중 Azure 대체/병렬 백업 요청을 건너뜁니다. 수동으로 Azure 공급자를 지정한 재시도는 계속 허용됩니다.
- 기본값은 켜짐입니다. 기존 사용자 설정에도 기본값 `true`를 적용해 업데이트 후 동작이 갑자기 바뀌지 않게 했습니다.
- 토글 상태는 브라우저 설정, Google Drive 사용자 설정 동기화, 암호화 설정 백업/복원에 포함됩니다.
- 앱 자산 캐시 버전과 빌드 표식을 갱신하고 회귀 테스트를 추가했습니다.

## 검증
`npm run check` 전체 통과. 실제 API 요청 및 배포 환경에서의 런타임 동작은 별도 실계정 테스트를 수행하지 않았습니다.

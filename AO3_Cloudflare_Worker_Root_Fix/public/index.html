번역 엔진 및 고유명사 단어장 설정

요청마다 키를 순환하고, 실패하면 나머지 키도 차례로 시도합니다. 같은 Google Cloud 프로젝트의 키는 사용 한도를 공유합니다.

* 아래 지정된 소설 번역 프롬프트를 시스템 지시문(System Instruction)으로 엄격히 준수하여 번역합니다.

짧은 문장으로 연결·할당량을 확인합니다.

Gemini와 Groq가 모두 실패했을 때 실행되는 마지막 API 번역 엔진입니다. Azure도 실패하면 비상용 무료 번역으로 넘어갑니다. 429는 요청 제한일 수 있습니다.

* 소설투(지문 -니다 금지), 서브컬처 통용 고유명사 최우선, 앞뒤 맥락 참조, 잘못된 줄바꿈 병합 및 장면 구분선 유지 지시가 번역 모델에 전달됩니다.

AI 번역 지침으로 전달하지 않습니다. 번역이 끝난 본문에서 왼쪽 문자열을 찾아 오른쪽 문자열로 직접 바꿉니다. 한 줄에 하나씩 입력하세요. 예: 일랴/일리야 또는 일랴 => 일리야.

    번역 일반 설정

    앱 테마

    다크·라이트·그린 중 원하는 테마를 선택하세요. 선택한 테마는 유지됩니다.

    * 소설투(지문 -니다 금지), 서브컬처 통용 고유명사 최우선, 앞뒤 맥락 참조, 잘못된 줄바꿈 병합 및 장면 구분선 유지 지시가 번역 모델에 전달됩니다.

    추가 지침은 번역 모델에 전달되는 일반 프롬프트에 덧붙습니다. 지원하지 않는 번역 엔진에서는 이 지침이 적용되지 않을 수 있습니다.

    AI 번역 지침으로 전달하지 않습니다. 번역이 끝난 본문에서 왼쪽 문자열을 찾아 오른쪽 문자열로 직접 바꿉니다. 한 줄에 하나씩 입력하세요. 예: 일랴/일리야 또는 일랴 => 일리야.

    API 설정 및 사용량

    직전 시도 키의 다음 키부터 순차 순환하며 묶음당 최대 2개 API 요청을 시도합니다. 냉각 중인 키는 건너뛰고 다음 사용 가능 키를 찾습니다. 같은 Google Cloud 프로젝트의 키는 사용 한도를 공유합니다. 자세한 시간은 “Gemini 키 냉각” 탭에서 확인하세요.

    * 아래 지정된 소설 번역 프롬프트를 시스템 지시문(System Instruction)으로 엄격히 준수하여 번역합니다.

    Google 응답이 503 UNAVAILABLE 또는 “experiencing high demand”이면 해당 모델을 5분부터 반복 과부하 시 점차 늘려 최대 1시간까지 냉각하고 다른 지원 Gemini 모델로 현재 문단을 재시도합니다. 냉각이 끝나면 선택 모델을 다시 우선 사용합니다.

    먼저 wrangler.jsonc에 AI 바인딩을 설정하고 배포하세요.
    짧은 문장으로 API 연결을 확인합니다.

    키만으로 계층을 자동 판별할 수 없어 직접 선택합니다. 실제 Azure 청구 주기·리소스의 한도는 포털에서 확인하세요.

    짧은 문장으로 연결·할당량을 확인합니다.

    켜져 있으면 Groq 요청이 지연되거나 실패할 때 Azure가 병렬 백업을 시작해 먼저 검증을 통과한 결과를 사용합니다. 자동 사용을 끄면 Azure 백업 요청은 보내지 않습니다.

    Gemini 키별 요청 수

    현재 활성 목록 기준으로 키별 요청 시도 수를 표시합니다. 일일 요청 수는 Google Gemini의 일반적인 태평양 시간 자정 리셋에 맞춰 초기화되며, 실제 프로젝트/모델 한도는 다를 수 있습니다. API 키 문자열은 표시하지 않습니다.

    키별 사용량을 불러오는 중…

    사용량 기록은 브라우저에 저장되며, Google Drive 연결 시 다른 기기와 동기화됩니다. 앱 밖 사용량은 포함되지 않을 수 있습니다. 키 여러 개는 서비스 한도 적용 범위를 확인할 수 없어 임의로 한도를 합산하지 않습니다.

    Gemini API 키 목록 관리

    여러 목록을 저장하고 번역에 사용할 활성 목록을 선택합니다. 각 키에는 안정적인 기본 고유번호가 부여되고, 목록에 포함되면 ‘목록 이름-목록 내 번호’로 표시됩니다. API 키는 Google Drive 암호화 설정 백업에 저장됩니다.

    새 키는 목록 안에서 다음 번호로 표시됩니다. 키를 삭제해도 기본 고유번호는 재사용하지 않습니다. 목록 이름을 변경하면 표시 이름도 함께 변경됩니다.

    Gemini 키별 냉각 상태

    현재 선택한 모델과 등록 키를 기준으로 표시합니다. 키 값 자체는 화면에 노출하지 않습니다. HTTP 429 응답만 키별 냉각을 시작하며, 503 과부하 보호는 별도로 작동합니다.

    번역 품질 검사 설정

    이 품질 검사는 Workers AI, Groq, Azure Translator에 적용됩니다. Gemini는 HTTP 요청이 성공하면 영어 잔존·문장 완결성·문단 수 품질 검사로 결과를 거부하거나 다음 키를 재호출하지 않습니다. 저장 시 빈 번역을 막는 챕터 완전성 보호는 별도로 유지됩니다.

    설정은 즉시 저장됩니다. 이 토글은 Workers AI, Groq, Azure Translator의 품질 검사에만 적용되며 Gemini 응답에는 적용되지 않습니다.

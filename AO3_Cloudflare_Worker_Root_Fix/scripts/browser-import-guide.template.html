Safari에서 서재로 보내기

아래에서 처음 한 번만 책갈피를 설정하세요. 그다음부터는 ChatGPT 공유 페이지에서 책갈피를 실행하면 번역문이 책장에 저장됩니다.

1. 실행 주소 복사

버튼을 누르면 책갈피에 넣을 주소가 복사됩니다.

복사가 안 되면 주소 직접 선택

아래 칸을 길게 누른 뒤 ‘전체 선택 → 복사’하세요.

2. 책갈피 설정 — 처음 한 번

  1. Safari의 공유 버튼(네모 위 화살표)을 누르고 책갈피 추가를 선택하세요.
  2. 이름을 서재로 보내기로 저장하세요.
  3. Safari의 책갈피 목록 → 편집에서 방금 만든 서재로 보내기를 선택하세요.
  4. 주소 칸을 전부 지우고 1번에서 복사한 실행 주소를 붙여넣으세요. 주소가 javascript:로 시작하는지 확인한 뒤 저장하세요.

3. ChatGPT에서 사용

  1. ChatGPT의 공개 공유 링크를 Safari에서 여세요.
  2. Safari 책갈피 목록에서 서재로 보내기를 누르세요.
  3. 서재가 열리며 작품 정보와 본문이 저장됩니다.

PDF 저장이나 본문 복사·파일 업로드는 필요하지 않습니다. 대화에 없는 저자는 자동으로 알아낼 수 없습니다.

이 도구는 사용자가 연 공개 공유 페이지의 번역문을 이 서재로 제출합니다. ChatGPT 로그인 정보는 가져오지 않습니다. Safari 계열 WebKit으로 실제 공유 링크와 배포된 서재 간 전송을 시험했습니다. iPhone의 책갈피 설정은 기기에서 진행해야 합니다.

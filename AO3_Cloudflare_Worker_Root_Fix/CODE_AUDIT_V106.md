# AO3 v106 전체 코드 감사 보고서

검토 기준일: 2026-10-27  
대상: `AO3_Cloudflare_Worker_Root_Fix` 전체 소스

## 발견한 문제와 수정

1. **동시 번역 묶음의 Gemini 소진 상태 공유**  
   서로 다른 번역 묶음이 공유 전역 플래그로 Gemini 키 순환 완료 여부를 전달하면, 한 묶음의 실패가 다른 묶음의 Gemini 시도까지 막을 수 있었습니다. 소진 상태와 공급자 오류 기록을 묶음별 상태 객체로 분리했습니다. 재시도 판단도 이전 작업에서 남은 전역 오류가 아니라 현재 묶음의 현재 라운드 오류를 기준으로 합니다.

2. **번역 중 특별 목록 키 표시가 바뀔 수 있음**  
   번역 도중 활성 목록을 바꾸거나 현재 목록에서 키를 삭제·이름 변경하면 진행 중인 요청의 라벨이 기본 키 번호로 표시될 수 있었습니다. 번역 시작 시 목록 ID·이름·키·목록 번호를 스냅샷으로 고정합니다. 작업실 상태 렌더러에서 `Gemini · 키 20-Fic Group-1 · ...` 형식이 텍스트·툴팁·접근성 이름에 반영되는 것을 DOM 단위 테스트로 확인했습니다. 기본 목록과 이름이 같은 특별 목록도 ID로 구분합니다.

3. **특별 목록 번호 충돌과 재사용 위험**  
   잘못된 백업이나 중복 번호가 들어오면 한 목록에서 같은 번호가 중복될 수 있었습니다. 목록 번호를 정규화하고 고유 번호를 보장하며, 삭제된 키의 번호는 저장된 번호표에 남겨 새 키가 기존 번호를 재사용하지 않게 했습니다. 중복 목록 이름은 구분되게 정규화합니다.

4. **오류 보고서의 API 키 비식별화 누락**  
   Azure 키 비식별화에서 설정 필드 이름을 잘못 참조하던 문제를 고쳤고, 현재 선택된 목록뿐 아니라 모든 특별 목록의 키를 비식별화 대상으로 포함했습니다. 실패 팝업의 원인·공급자별 세부 내용도 동일한 비식별화를 거칩니다.

5. **오류 보고서 저장 실패를 성공처럼 안내할 수 있음**  
   브라우저 저장소가 가득 차거나 차단되면 보고서 대기열 저장이 실패해도 기존 흐름은 이를 호출자에게 알리지 않았습니다. 저장 함수가 성공 여부를 반환하고, 저장 실패 시 팝업이 저장되었다고 주장하지 않고 원인 기록을 복사해 보관하도록 명확히 안내합니다. Drive 연결 상태와 로컬 대기열 저장 상태도 구분합니다.

6. **번역 품질 옵션과 실제 검사 분기 일치 여부**  
   문단 수 옵션을 브라우저와 Worker 양쪽에서 동일하게 처리하도록 확인·수정했습니다. 검사를 끄면 초과 분할된 문단을 복구하도록 시도하지만, 빈 결과나 누락 문단처럼 안전하게 정렬할 수 없는 결과는 저장하지 않습니다. 영어 잔존·불완전한 문장 검사는 공통 품질 검사 함수에서 옵션값을 실제로 확인합니다. 두 옵션의 켜짐/꺼짐을 함수 실행으로 검증했습니다.

7. **Gemini 전체 키 순회 및 냉각 토글**  
   각 번역 묶음에서 등록 키 목록의 두 차례 전체 순회를 실행하는지 모의 API로 확인했습니다. 냉각이 꺼져 있으면 기존 냉각 기록이나 새 HTTP 429가 키의 두 번째 요청을 막지 않습니다. 냉각이 켜져 있으면 냉각 중인 키를 두 차례 모두 고려하되 실제 요청은 생략합니다. 따라서 “두 차례 순회”는 유지되지만, 냉각이 켜져 있는 키가 실제 API에 두 번 호출되는 것은 의도적으로 보장하지 않습니다. 모든 공급자가 실패하면 공급자별 원인을 포함한 오류가 발생하고 보고서·팝업 흐름에 전달됩니다.

8. **암호화 Drive 백업 복원**  
   AES-GCM 암호화·복호화 함수를 실제 실행해 여러 특별 목록의 모든 키, 활성 목록, 키 ID, 냉각 스위치, 품질 검사 스위치가 왕복 복원되는 것을 검증했습니다. 잘못된 암호는 거부됩니다.

## 검증 범위의 제한

- 실제 Gemini API 키를 이용한 네트워크 번역, 실제 Google Drive 계정 업로드·다운로드는 수행하지 않았습니다. Drive 테스트는 실제 암호화 함수로 로컬 왕복을 확인한 것입니다.
- 설치된 Chromium이 이 실행 환경에서 `about:blank` 및 로컬 페이지의 headless 실행을 완료하지 못해 실제 브라우저 화면 스크린샷 검증은 불가능했습니다. 대신 실제 상태 렌더러 함수를 DOM 모형에서 실행했습니다.
- 프로젝트에 Wrangler 의존성이 로컬 설치되어 있지 않았고 `npx wrangler deploy --dry-run`이 시간 초과되어 Worker 배포 빌드 검증은 완료하지 못했습니다. Worker 소스 구문 검사와 기존 Worker 테스트는 통과했습니다.
- GitHub 커밋과 Cloudflare 배포는 수행하지 않았습니다.

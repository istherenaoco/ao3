# Gemini 키 순차 순환 및 냉각 상태 v102

- 요청마다 직전 시도 키 다음에서 시작하도록 round-robin 커서를 이동하고 브라우저 로컬 저장소에 기억합니다.
- 묶음당 최대 두 번의 실제 Gemini 요청은 유지하되 냉각 키를 후보로 세는 대신 다음 키를 검색하므로, 앞의 키가 냉각 중이어도 이후 키가 사용됩니다.
- HTTP 429의 키/모델별 냉각은 활성화 여부를 확인하여 기록·적용합니다. 끄면 해당 냉각 기록을 우회하고 신규 429는 키 냉각으로 저장하지 않습니다. 503/high-demand 모델 보호는 별개로 유지됩니다.
- API 설정 모달에 `Gemini 키 냉각` 탭을 추가했습니다. 각 키 번호별 상태, 재시도 예정 시각, 남은 시간이 표시되며 1초마다 갱신됩니다. 실제 키 문자열은 표시하지 않습니다.
- 냉각 설정은 로컬 설정, Google Drive 사용자 설정 및 암호화 설정 백업/복원에 포함됩니다.

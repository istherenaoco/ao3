# Bookmark defaults and tag examples (v14)

- Novel-level bookmarks are opt-in: the “save as bookmark” checkbox starts unchecked.
- After a save or append, the checkbox and manual tag field reset so a prior choice does not silently affect the next novel.
- Starter/demo novel and passage bookmarks are off by default. Existing saved user data is not migrated or unbookmarked.
- Removed canned examples such as reading/completed/rec-read/quotes/foreshadowing/highlights/fantasy. The only built-in tag examples are `#angst` and `#BDSM`.
- Applied changes to `index.html`, `ao3.html`, `public/index.html`, and `public/ao3.html`.
